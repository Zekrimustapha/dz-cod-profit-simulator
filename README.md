# DZ COD Profit Simulator

Profit calculator for Cash-on-Delivery e-commerce in Algeria. Static single-page app (no build step), English / Francais / Arabic.

**Tabs:** Overview (verdict, break-even, cost breakdown, funnel) - Landed cost (China to Algeria) - Ad funnel (CPM to cost per order) - Regions (delivery rate by zone) - Price lab - Bundles - Scenarios - Sensitivity - Risk (3,000-run simulation) - Cash flow - Monthly P&L (fixed costs, reorders, scaling) - Test plan - Saved products (compare, CSV, JSON import/export, share link).

All figures are estimates driven by your inputs. Saved products stay in your own browser (localStorage).

Deploy: any static host. On Vercel, import this repo with the "Other" framework preset and no build command.
